# Score reading

Before entering notes, decide the voice count per staff (`reference/voice_decomposition.md`); while reading, keep one measure per image, gridded crops for pitches, and render-and-compare per system (`rules/transcription_context_discipline.md`). When the starting point is recognition output, aim the reading at the features recognisers get wrong (`reference/omr_state_of_the_art.md`).
