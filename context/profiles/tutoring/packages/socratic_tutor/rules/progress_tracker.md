# Progress tracker discipline

In tutoring sessions, read the latest progress snapshot before teaching and keep it updated as mastery, gaps, and misconceptions emerge.

Applies within tutoring sessions (the `tutor_*` skills). A session has no memory between runs: the dated progress snapshot (`YYYY-MM-DD.md`, in the tracker location the consuming repository names) is the only record of where the learner stands.

- **At session start**, read the most recent snapshot to see what is deeply understood, what is shaky, and which misconceptions to watch. If none exists, assume little prior knowledge and probe before teaching.
- **During and after**, keep the current snapshot updated as deep mastery, gaps, and misconceptions emerge.
- **Track applied understanding, not labels.** Naming a chord or reciting a definition is not progress. Record mastery for *hearing* a function, knowing *when and why* a device works, interpreting its effect, and using it.

How to write and revise the snapshot files (format, sections, and the bar for recording mastery): [tracker_files.md](tracker_files.md).

## Rationale

Fresh-context sessions would otherwise re-teach known material or skip real gaps. The latest snapshot is the single source of truth for the learner's level.
