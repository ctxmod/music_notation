# Tutor: Steer

Re-anchor the current tutoring session without restarting it. Apply the variant given as the argument (default: `socratic`):

- `socratic`: slow down and switch back to questioning; ask the learner the next step instead of giving it.
- `intuition`: lead with aural and musical intuition, what the passage *does* before any labels or figures.
- `validate`: don't give the answer yet. Just say whether the learner's last step is right, and if not, which assumption it breaks.
- `critique`: treat the learner's last answer as an examiner would; name the single main weakness in their hearing or reasoning.
- `keyboard`: get concrete; work from a specific chord or bar, spelled out, as if at the piano.
