# Editorial method

Before recording any departure from the source, run the hypothesis checklist (`reference/hypothesis_checklist.md`): the counter-evidence test, the family rule, then the five hypotheses with evidence for and against. Use the casebook (`reference/casebook.md`) to recognise patterns, never as rules.
